How to read this

The ClickUp Doc is the primary deliverable — it carries the audit findings, the strategic reframe, and the six-phase roadmap. The two prototypes below are the visual companions: Level 1 makes the audit findings tangible, Level 2 makes the roadmap concrete. The Figma file carries the design system — color and type tokens, components, and the Settings Screen progression from current to proposed to future state.

Suggested order: Doc first, then Level 1, then Level 2. Each prototype takes about five to seven minutes to scroll through; the Figma file is a quick three-minute skim.
