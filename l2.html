L2 Prototype · Future State · AI Custom Fields

From form to workflow.

Today, creating an AI Custom Field means configuring control after control, committing to a prompt blind, and hoping the model picks up the right signals.

Tomorrow, AI Custom Fields are a first-class Brain-native product system — not a bolt-on form. Brain builds them. The workspace measures them. Every screen in ClickUp consumes them.

1 Phase 4A
Templates arrive configured
Picking a template auto-fills Field name, Prompt, Format, and Automations. No blank forms. Three new templates ship with this phase — Meeting Notes, Stakeholder Update, Decision Log — each a curated one-click workflow.
2 Phase 2
Brain helps, live
The sidebar docks alongside the form and watches your prompt edits. Suggestions land as actionable proposals — “Add linked docs,” “Pull recent status changes” — with Apply / Not now right on the card.
3 Phase 3
Preview across tasks, not just one
Tab between sample tasks and see how the prompt performs on each. Every preview runs Brain's quality check: does it mention blockers, dates, owners? Catch bad prompts before they hit production.
4 Phase 2
Variables as pills, cross-platform consistency
Pill chips bring this view in line with how Chat, Super Agents, and Saved Prompts already render variable references across the product. One visual pattern for any task-field reference — branded design across every Brain-touched control.
5 Phase 3
Cost visible, budget enforced
Brain credit cost shown before the user clicks Create. No surprise billing. Per-field usage clickable through to the dashboard in Act 3 — which extends the AI Super Credits screen that ships today.
6 Phase 2
Model picker per field
Power users pin a specific model for fields where it matters — GPT for structured extraction, Claude for long-form writing. Defaults to Brain Auto. Mirrors the model picker in Chat and Super Agents.

5Act Five · The future, further

Three bets, one horizon.

Phase 5 and beyond. What Brain-native AI Custom Fields become when the foundation — Acts 1–4 — is in place. None of these are speculative — each rides on capability that ships today or in phases above.

Card 1 Phase 5
Describe the field. Brain drafts the field.
A pre-Settings entry point. Describe what you want in one sentence. Brain proposes a fully configured AI field — name, template, prompt, output format, automations — then opens the Settings Screen pre-populated so you review, tweak, and ship.

Reuses: Brain's natural-language interface + Super Agents' builder pattern. The Settings Screen becomes the tweak pane, not the creation pane.

Card 2 Phase 5
Fields that reference each other.
A project's Weekly Update references its Risk Score. The Risk Score references its Blocker Summary. Native fields like Due date feed the system. Fields become composable building blocks — each reads the outputs of others, and the workspace's state flows through the graph.

Reuses: Brain's cross-field reasoning (already powering chat-style queries today). A dependency check prevents runaway cost.
Card 3 Phase 5+
When a Super Agent owns the field.
This card makes concrete the argument the Strategic Reframe already makes: AI Custom Fields and Super Agents are two points on a spectrum, not two separate products. A dropdown starts as a Sentiment classifier. It accumulates reasoning, then approval flows, then cross-field logic. At some point it's indistinguishable from an agent whose output happens to be a field value — and that's the point. Teams start simple and grow into sophistication without picking a product.

Reuses: Super Agent instructions, skills, and memory — extended so one of the agent's outputs is a field value the workspace treats as canonical.
