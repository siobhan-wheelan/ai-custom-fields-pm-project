# AI Custom Fields — PM Interview Project

Two working prototypes that walk the present and future of ClickUp's AI Custom Fields. Companion to the primary deliverable, a ClickUp Doc that carries the audit, the strategic reframe, and a six-phase roadmap.

**Author:** Siobhan Wheelan · April 2026
**Audience:** Product + Design leadership at ClickUp

## What's hosted here

- `index.html` — landing page, links to both prototypes
- `l1.html` — Level 1 prototype: present-state, unified. Audit findings made tangible
- `l2.html` — Level 2 prototype: future-state, Brain-native. Roadmap made concrete
- `images/` — popout screenshots and design assets referenced by the L1 prototype

## How to view

Open `index.html` in any modern browser, or hit the GitHub Pages URL once the repo is published.

Each prototype takes about 5–7 minutes to scroll through. The companion ClickUp Doc carries the full argument and is the recommended starting point — see the landing page for the link.

## Local preview

```bash
cd hosting
python3 -m http.server 8000
# open http://localhost:8000
```

## Notes

Built with hand-written HTML, CSS, and a small amount of vanilla JS. No build step. Designed for 1440px viewport at 100% zoom.
